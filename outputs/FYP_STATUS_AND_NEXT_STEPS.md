## 接下来按这个顺序

1. **修复线上登录链路：** 当前已登录浏览器会话仍在“我的记录”看到 HTTP 404；先用分阶段错误提示确认失败环节，再针对该环节修复并重新核验。需要提交新记录前，先用无个人信息的合成图片；提交会在公开网站新增记录，当前线上两条测试记录继续保留。
2. **确认研究范围：** 让导师决定 A/B/C 方法、主要指标、固定候选池结论范围、样本设计及公开数据集/受控采集路径。未确认前不把方案草案视为批准。
3. **完成伦理与数据处理门槛：** 按学院流程确定是否审批、同意文本、图片存储和删除规则、DeepSeek 第三方处理许可；批准前不收集或发送研究照片。
4. **先做获批 pilot：** 小规模验证记录字段、双人标注、数据覆盖和流程；据此确定正式样本量并冻结分析方案。
5. **正式实验与论文结果：** 按物品身份隔离 development/test，固定提示词和模型设置，运行 A/B/C；报告指标、失败、延迟、真实 API 费用及限制，再填写结果章。
6. **收尾线上验收：** 逐项复核登录后发布、Blob、DeepSeek、跨账号记录隔离、关闭/删除和自动到期清理。只报告实际完成的检查。
