# 第 1 章：引言（讨论用草稿）

> 状态：中文规划稿，尚未按学院模板、字数或引用格式修订。研究问题、数据来源和伦理安排仍待导师/学校确认。本文不声称研究空白已被系统检索证明，也没有实验结果。

## 1.1 研究背景

失物与拾获物品的记录可以包含照片、物品类别、颜色、描述、地点和时间等线索。若失主和拾获者需要逐条浏览记录，系统可以尝试把一条失物记录与外观和时空信息相近的拾获记录排在一起，供用户进一步核对。

已有研究探索了多种路线。Ghazal 等（2016）描述了把文字搜索、地理信息筛选、SURF 图像匹配和颜色验证结合起来的失物检索系统。Zhou 等（2024）的 LostNet 使用 MobileNetV2、CBAM 和感知哈希处理失物照片；论文报告的 96.8% 是图像类别分类准确率，不能直接解释为同一物品配对或前 K 名检索准确率。Hirose 等（2022）研究了只登记图片的失物检索，Das 等（2026）则描述了用 MobileNet 图像嵌入进行候选检索。近期也有结合 YOLO、LLM 和 CLIP 的失物多模态检索工作。这些研究说明，照片分类、图像检索和失物信息排序均已有先例；因此，本项目不把“用 AI 做失物照片匹配”本身作为已证实的新颖贡献。

## 1.2 问题陈述

本项目关注的具体问题是：在一个给定的失物查询和一组拾获候选中，系统能否把“同一件实物”的记录排得更靠前。表单信息（如类别、颜色、粗略地点和时间）可提供检索线索；照片分析可补充颜色、品牌和可见特征；对少量候选照片进行直接比较，则可能提供额外的外观线索。但同类别或同颜色不代表是同一件实物，视觉相似也不能证明所有权。

目前的项目资料还没有证明哪种方法在本项目数据上更好。LostNet 报告的分类准确率、其他论文的摘要结果，以及公开网站上的匹配分数，都不能替代在相同候选集合和可靠实物身份标签上的本地比较。因此，本研究拟建立经批准、匿名化并有人工配对标签的数据，再比较表单、结构化视觉属性和候选照片比较三种排序方法。此问题与其数据方案仍须导师确认。

## 1.3 研究目标

本项目的目标是实现一个手机和电脑浏览器均可使用的失物照片配对原型，并在获批的数据与研究流程下，评估照片信息对候选排序的增量作用。

## 1.4 研究任务

1. 实现失物/拾获记录发布、照片上传、公开候选查看和个人记录管理。
2. 实现只用表单信息的基线排序，并加入可选的 DeepSeek-V4.1-Flash 照片属性提取与候选照片比较。
3. 制定匿名记录、实物身份分组、人工配对标注和开发/测试划分方案；在导师/学校批准前不把真实参与者数据用于研究或发送到第三方 AI。
4. 使用同一查询、候选池和配对标签，暂以 Hit Rate@5 为建议主要指标、Recall@5 和 MRR@5 为次要指标，并记录模型调用时延、失败和实际费用；最终指标待导师确认。
5. 分析错配案例和限制，不把排序分数解释为概率、所有权证明或现实找回率。

## 1.5 研究问题

- **主要研究问题：** 在相同且有可靠实物身份标签的查询与候选集合上，完整视觉流程相较仅使用表单信息，是否提高 Hit Rate@5？
- **次要组件问题：** 结构化视觉属性相较表单基线的增量是多少？在属性排序后加入候选照片直接比较，相较属性方法的增量是多少？
- **运行问题：** 视觉方法的响应时间、失败率和实际 API 费用是多少？

以上均为待导师确认的问题。当前建议把完整视觉流程对表单基线的 Hit Rate@5 差值设为唯一确认性主要比较；组件增量、Recall@5 与 MRR@5 为次要/探索性分析。均匀随机排序期望值只作为候选池难度参考，不是应用功能或第四个 AI 方法。最终统计方案必须在查看测试集结果前确定。

## 1.6 项目范围

系统面向手机和电脑浏览器，不开发原生 Android/iOS 应用。用户可发布“丢失”或“拾获”记录，填写类别、颜色、粗略地点、大概时间和说明，并上传照片。登录用户可查看和管理自己发布的记录；访客可浏览公开记录。系统最多显示前五个候选及其排序依据。

视觉处理只在发布者对该记录明确同意且 DeepSeek API 已配置时进行；直接比较候选照片还要求候选记录发布者也已同意。未同意或 API 不可用时，系统仍可使用表单信息排序。记录照片目前公开展示，参考分不是概率。此应用同意选项不等于学校伦理审批或研究参与者同意。

研究评估限定于离线排序比较及运行指标。实时通知、聊天、认领验证、管理员审核和原生手机 App 不在当前 MVP 范围内。可用性研究只有在导师和学校许可后才进行。

## 1.7 研究意义与预期贡献

项目的实际产出是一个可运行的响应式失物记录和候选排序原型。研究产出则取决于能否获得批准且标签可靠的数据：在相同候选池上比较表单信息、结构化视觉属性和候选照片比较，报告排序指标、调用成本和错配模式。该研究不预先假定视觉模型一定改善结果；如果没有可靠的同一实物正例，便不能用同类别照片替代，也不能据此得出配对性能结论。

## 1.8 关键术语

- **同一实物正例：** 失物查询照片和拾获候选照片经可靠证据确认属于同一件具体物品，而不是仅属同一类别或同款。
- **困难负例：** 类别、颜色或外观相似，但有依据确认并非同一件实物的候选。
- **Hit Rate@5：** 对每条查询，检查前五名中是否至少有一个已确认正例，再对查询取平均。
- **Recall@5：** 对每条查询，计算已确认正例中有多少排进前五名，再对查询取宏平均。
- **MRR@5：** 取前五名里第一个已确认正例排名的倒数；没有正例进入前五名则记为 0，再对查询取平均。
