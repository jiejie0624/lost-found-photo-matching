# FYP 导师讨论与确认清单

> 讨论用工作表，不是伦理审批、数据授权或正式 proposal。所有空栏应由学生与导师讨论后填写；未确认前不得把建议视为批准。

## 项目建议

**暂定题目：** 结合视觉属性与时空信息的失物配对系统

**核心研究问题：** 在相同的查询、候选集合和人工配对标签下，加入照片提取属性，或对初筛候选进行照片直接比较，是否比只用表单信息更常把真实失物/拾获配对排入前 5 名？

**比较方法：**

1. 表单基线：用户填写的类别、颜色、地点、时间和说明。
2. 视觉属性：在表单基线上增加照片中的类别、颜色、可见品牌和显著特征。
3. 候选照片比较：对视觉属性方法初筛出的前 5 个候选进行照片比较并重排。

**主要指标建议：** Hit Rate@5、Recall@5、MRR@5；按物品身份分组划分开发集/测试集，报告方法差异的不确定性。记录模型调用耗时、失败和实际费用。任何匹配分数都只表示排序参考。

## 开始收集或上传研究数据前的门槛

- 研究问题、数据来源、同意和删除流程已由导师确认。
- 学校确认所需伦理审批，并在需要时取得批准。
- 学校/导师明确允许的存储位置、访问范围和第三方 API 处理方式。
- 若使用真实照片，已确认照片拍摄者或物品所有者的授权范围；照片中不含不必要的个人资料。
- 开发集和测试集按实物身份分组；测试标签和模型设置的冻结方式已写明。

伦理办公室或导师尚未答复时，继续做模拟数据、代码和不涉及真实个人资料的技术准备；不要把网站已公开部署、Neon Auth 已启用或图片已去除 EXIF 当成研究伦理批准。
