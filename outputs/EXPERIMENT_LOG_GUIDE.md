# 模型实验调用日志指南

空白表格：[`experiment_log_template.csv`](experiment_log_template.csv)

## 记录规则

- 每次视觉 API 请求记录一行；照片属性提取与候选照片比较使用不同的 `request_type`，例如 `attribute_extraction` 和 `photo_comparison`。
- 在试验前分配 `run_id`，记录数据集版本及 `development` 或 `test` 划分。测试集应在方法、提示词和预处理流程冻结后调用。
- `item_group_id` 使用匿名的实物分组编号，便于按实物分组分析；不可写姓名、邮箱、账号或联系方式。
- `model_id`、`prompt_version`、`image_preprocess_version` 和 `image_count` 用于说明本次请求设置。若提示词会变动，用版本号或 SHA-256 摘要标识，并将完整提示词保存在受限的研究材料中。
- 按 API 返回用量填写输入、缓存命中输入和输出 token；若没有返回用量，留空并在 `notes` 说明，不要估填。
- `latency_ms` 从请求发出到完整响应收到为止。失败请求也要记录 HTTP 状态、重试次数和结果；不要在日志里写 API 密钥或完整错误内容。
- `estimated_cost_usd` 依据调用当天官方价格和实际 token 用量计算；同时填写核价日期。免费或失败请求也按真实计费记录，不预设为零。
- 每次人工调整或排除数据，另记原因和操作者的匿名编号；不要覆盖原始行。

## 隐私与保存

CSV 只保存匿名编号、模型设置和运行指标。不要将图片、姓名、电子邮件、访问令牌、API 密钥、精确地点或未经批准的真实描述写入日志。保存位置、访问权限和删除期限以导师及学校批准方案为准。移除 EXIF 不代表照片本身不含隐私信息。

日志只能说明 API 运行情况，不能替代配对标签、离线排名指标或伦理批准。尚未获得审批的数据不得为填日志而上传到 DeepSeek 或其他第三方服务。
